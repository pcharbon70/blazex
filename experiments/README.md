# Experiments

This directory contains bounded architecture proofs required before public
contracts can stabilize. Experiments are not supported products, reusable
packages, or promises about the eventual implementation technology.

Each experiment must state the question it answers, the contracts it exercises,
its completion and removal criteria, and which results move into reusable
packages or conformance fixtures.

- `native_renderer_spike` tests whether the host-neutral semantic contracts can
  drive actual native controls before the browser API is frozen.
