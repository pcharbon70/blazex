# BlazeX BH-02 Host-neutral Contract Baseline v0.1.0

## Decision

BH-02 is accepted with bounded conditions at internal experimental scope. The
baseline is eligible for consumption by a separately authorized BH-03. It
does not grant public API stability, package publication, production use,
platform qualification, accessibility conformance, or support.

## Change and downstream boundary

Material contract changes must supersede this baseline through a governed ADR
and compatibility review. BH-03 is eligible but remains unauthorized until a
separate repository-owner authorization names its scope, base revision,
delivery rules, and evidence contract.
