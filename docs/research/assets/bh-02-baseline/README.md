# BH-02 Semantic Kernel Baseline Assets (`bh-02-baseline`)

## Purpose

This directory records BH-02 authorization, inherited entry truth, repository
activation, validation, and phase evidence without modifying the immutable
BH-01 feasibility release.

## What belongs here

- Explicit phase authorization and synchronized branch provenance.
- A ledger importing BH-01 entry requirements, conditions, limitations,
  forbidden leakage, and evidence states.
- Repository activation and dependency-policy manifests.
- Validation schemas, logs, and phase completion decisions.

Semantic implementations and test fixtures belong in their owning packages or
integration directories. Generated build products and external dependencies do
not belong here.

## Maintaining this index

Index every direct asset. Preserve prior versions, bind evidence by hash, and
add a superseding record rather than rewriting a completed decision. No phase
may change an inherited condition or evidence state without an explicit,
reviewed amendment.
