# BH-03 Browser Host Baseline Assets (`bh-03-baseline`)

## Purpose

This directory records BH-03 authorization, inherited entry truth, lifecycle
contracts, repository activation, validation, and phase evidence without
rewriting the accepted BH-02 baseline or disposable BH-01 evidence.

## What belongs here

- Explicit phase authorization and synchronized branch provenance.
- The BH-03 entry ledger and versioned lifecycle contract envelopes.
- Repository activation, validation logs, and completion decisions.
- Versioned evidence overlays that never edit the canonical planned registry.

Runtime implementation and tests belong in their owning packages and
integration directories.
