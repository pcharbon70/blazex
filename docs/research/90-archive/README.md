# Archive (`90-archive`)

## Purpose

The archive retains inactive, superseded, or abandoned work whose context
remains useful.

## What belongs here

Move dormant work here when deletion would erase research history. Record why
it was archived and link any replacement; temporary clutter belongs in the
inbox or should be removed.
