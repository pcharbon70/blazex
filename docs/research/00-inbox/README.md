# Inbox (`00-inbox`)

## Purpose

The inbox holds captures that have not yet been classified or developed.

## What belongs here

Put rough questions, unprocessed links, temporary excerpts, and incomplete
notes here. Promote valuable material during review; do not use the inbox as
permanent storage.
