# BH-03 Phase 2 pre-acquisition fixtures

This directory owns the versioned, pure-data fixtures for compatibility
identity, manifest discovery, prerequisite evaluation, and strict profile
manifest validation. The fixtures exercise only the gate before artifact
acquisition; they contain no fetched artifact, started runtime, registered root,
browser result, measurement, or acceptance evidence.
