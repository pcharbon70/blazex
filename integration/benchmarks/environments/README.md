# BH-01 Benchmark Environments

Fingerprint records for authorized build and browser environments are stored
here. `bh01-phase8-local-linux.json` records the one local Linux/Chrome
environment available to Phase 8. The four unavailable required browser rows
remain `environment-blocked` in the browser-matrix catalog.

Phase 9 adds separate fingerprints for the Linux build context, Chrome for
Testing 152.0.7977.75, and the Playwright patched Firefox 153.0 development
build. The Firefox fingerprint is explicitly experimental, unsupported, and
ineligible for stable required-row credit.
