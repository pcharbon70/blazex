# BlazeX Surfaces

Owns transient and layered UI abstractions such as dialogs, drawers, menus,
popovers, tooltips, snackbars, focus scopes, placement, and stacking.

The package defines portable surface intent and coordination. Portals, browser
focus APIs, windowing systems, and native overlay primitives remain renderer or
host responsibilities.

Status: directory scaffold only; create the Mix project when its implementation
milestone begins.
