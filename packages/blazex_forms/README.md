# BlazeX Forms

Defines client-safe form, field, input, conversion, validation, error, and
submission semantics. It will host form-oriented components whose concerns are
substantial enough to evolve independently from the general UI package.

Browser details such as native input elements and server details such as
Phoenix changesets must be introduced through adapters, not the core form
contracts.

Status: directory scaffold only; create the Mix project when its implementation
milestone begins.
